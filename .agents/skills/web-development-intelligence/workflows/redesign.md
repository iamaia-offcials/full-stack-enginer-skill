# Workflow: Website Redesign & Modernization

Transform an outdated or generic interface into a distinctive, high-converting digital experience.

## Procedure

1. **Audit & Defect Inventory:**
   - Run `node scripts/validate-design.mjs` on the legacy code.
   - Document layout shifts, broken touch targets, AI tells, and visual hierarchy flaws.
2. **Preserve Domain Invariants:**
   - Keep working backend integrations, SEO URL structures, analytics tags, and form submission endpoints intact.
3. **Elevate Typography & Composition:**
   - Increase scale contrast (hero headline to body ratio).
   - Reorganize sections according to industry UX patterns.
4. **Harden Responsive States:**
   - Resolve mobile horizontal overflow, fix input zoom traps, and verify keyboard navigation.
