# Workflow: Adding a New Page Route

Design and implement a new subpage within an existing web property.

## Procedure

1. **Define Route Contract:**
   - Purpose, URL slug, access control, and metadata title/description.
2. **Re-use Foundation Tokens:**
   - Import existing layout shell, navbar, and footer.
   - Compose page using existing shared UI primitives.
3. **Responsive Flow & Section Rhythm:**
   - Sequence sections to answer specific user questions.
   - Verify mobile column stacking and touch targets.
