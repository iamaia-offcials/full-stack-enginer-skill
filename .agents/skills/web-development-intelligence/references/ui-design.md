# User Interface (UI) Design

Visual hierarchy, component density, and tactile digital craftsmanship.

## Interface Elements & Spatial Rules

1. **Visual Hierarchy Construction:**
   - Establish three distinct reading layers: **Hero/Display** (primary focal point), **Structural Body** (core narrative), and **Metadata/Context** (subtle labels, captions).
   - Adjacent sizes must differ by at least 25–30% to establish unambiguous hierarchy. Sizes separated by only 1–2px read as alignment errors.

2. **Card & Container Architecture:**
   - **Density Consistency:** Do not mix loose editorial cards with hyper-dense data cards on the same screen without deliberate rationale.
   - **The Single Box Principle:** Avoid nesting boxes inside boxes inside boxes. Use subtle tone shifts, borders, or whitespace instead of multiple layered card containers.
   - **Padding Harmony:** Internal card padding must equal or exceed the gap between adjacent cards to maintain Gestalt grouping.

3. **Action Button Hierarchy:**
   - **Primary Action (Max 1 per section):** High-contrast filled button representing the primary goal.
   - **Secondary Action:** Outlined or subtle neutral background for alternative paths.
   - **Tertiary / Ghost Action:** Text-only or subtle icon for contextual, low-priority utilities.
   - **Destructive Action:** Red/danger styling requiring explicit confirmation dialog for irreversible operations.
